# Metrics

Generated by `jellyfin-merge-proxy --metrics-md`. All metrics are Prometheus-formatted at the configured `[metrics]` endpoint. Process metrics (`process_cpu_seconds_total`, `process_resident_memory_bytes`, `process_open_fds`, ...) are added by the `metrics-process` crate when `process_metrics = true`.

| Name | Type | Labels | Meaning |
|---|---|---|---|
| `jmp_http_requests_total` | counter | route, method, status | Client HTTP requests handled, by route template, method and status code. |
| `jmp_http_request_duration_seconds` | histogram | route, method | Time until response headers were produced (streams: excludes body transfer). |
| `jmp_http_requests_in_flight` | gauge | - | Client requests currently being processed (headers not yet sent). |
| `jmp_http_response_size_bytes` | histogram | route | Response body size when known up-front (Content-Length). |
| `jmp_http_errors_total` | counter | kind | Requests that failed inside the proxy, by error kind (unauthorized, not_found, upstream_unavailable, upstream_error, bad_request, payload_too_large). |
| `jmp_stage_duration_seconds` | histogram | stage | Duration of internal pipeline stages: auth, id_decode, fanout, rewrite, merge, dedupe, sort_page, serialize, views_build. |
| `jmp_fanout_upstreams` | histogram | endpoint | Number of upstreams queried by one fan-out request. |
| `jmp_fanout_upstream_results_total` | counter | endpoint, server, outcome | Per-upstream result of fan-out calls: success, http_error, timeout, error, skipped (endpoint=views: library list refresh). |
| `jmp_fanout_partial_total` | counter | endpoint | Fan-out responses served with results from only some of the targeted upstreams (endpoint=views: a server's libraries were missing from the list). |
| `jmp_fanout_slowest_seconds` | histogram | endpoint | Time spent waiting for the slowest upstream of a fan-out. |
| `jmp_ids_encoded_total` | counter | server | Upstream ids rewritten to proxy ids. |
| `jmp_ids_new_total` | counter | server | New entries added to the id mapping table. |
| `jmp_ids_decoded_total` | counter | outcome | Proxy id lookups: hit, view, miss, invalid. |
| `jmp_ids_table_size` | gauge | server | Entries in the id mapping table. |
| `jmp_merge_items_in_total` | counter | endpoint | Items received from upstreams for merged lists. |
| `jmp_merge_items_out_total` | counter | endpoint | Items returned to clients from merged lists (after dedupe and paging). |
| `jmp_dedupe_dropped_total` | counter | key | Duplicates removed, by match key: tmdb, imdb, tvdb, title (search hints: type+name+year), index (season/episode number of a show split across servers), name. |
| `jmp_dedupe_winner_total` | counter | server | Dedupe decisions won by each upstream. |
| `jmp_library_groups` | gauge | kind | Library views presented: merged (combined across servers) or single. |
| `jmp_cache_requests_total` | counter | cache, outcome | Catalog cache lookups: hit, miss, stale (refresh forced/expired). |
| `jmp_cache_entries` | gauge | cache, server | Entries held in the catalog cache. |
| `jmp_cache_bytes` | gauge | cache, server | Approximate serialized size of the catalog cache. |
| `jmp_cache_refresh_duration_seconds` | histogram | cache, server | Duration of catalog refresh calls to an upstream. |
| `jmp_cache_refresh_failures_total` | counter | cache, server | Failed catalog refreshes. |
| `jmp_cache_last_refresh_timestamp_seconds` | gauge | cache, server | Unix time of the last successful catalog refresh. |
| `jmp_cache_evictions_total` | counter | cache | Catalog cache entries replaced/evicted. |
| `jmp_persist_ops_total` | counter | store, op, outcome | Persistence operations (ids, siblings and sessions: load and save). |
| `jmp_db_journal_mode` | gauge | mode | 1 for the SQLite journal mode in effect (read back from SQLite after applying `[database] journal_mode`), 0 for the other modes. |
| `jmp_db_schema_version` | gauge | - | Schema version of the state database after migrations. |
| `jmp_db_imported_rows_total` | counter | kind | Rows imported from the pre-database files (ids.tsv, siblings.tsv, sessions.json) on first start. |
| `jmp_upstream_requests_total` | counter | server, endpoint, status_class | HTTP requests sent to upstreams by route template and status class (2xx..5xx, error). |
| `jmp_upstream_request_duration_seconds` | histogram | server, endpoint | Upstream time to response headers. |
| `jmp_upstream_errors_total` | counter | server, kind | Upstream transport errors: connect, dns, tls, timeout, body, other. |
| `jmp_upstream_in_flight` | gauge | server | Concurrent requests to each upstream (headers pending). |
| `jmp_upstream_up` | gauge | server | 1 if the upstream is considered healthy, 0 while in back-off. |
| `jmp_upstream_retries_total` | counter | server, reason | Upstream request retries (reason: unauthorized). |
| `jmp_upstream_reauth_total` | counter | server | Re-authentications triggered by a 401. |
| `jmp_upstream_auth_total` | counter | server, outcome | Upstream logins: success, failure, unreachable. |
| `jmp_upstream_token_age_seconds` | gauge | server | Seconds since the upstream token was obtained. |
| `jmp_sessions_active` | gauge | - | Proxy client sessions (issued tokens). |
| `jmp_logins_total` | counter | outcome | Proxy logins: success, unknown_user, bad_password, bad_request. |
| `jmp_token_validations_total` | counter | outcome | Client token checks: valid, invalid, missing, anonymous. |
| `jmp_argon2_duration_seconds` | histogram | op | argon2 hash/verify time. |
| `jmp_streams_active` | gauge | server, kind | Response bodies currently being streamed (kind: direct, hls_segment, hls_playlist, transcode, image, download, web, other). |
| `jmp_stream_bytes_total` | counter | server, kind | Bytes streamed from upstreams to clients. |
| `jmp_stream_ttfb_seconds` | histogram | server, kind | Time from upstream request to first body byte. |
| `jmp_stream_end_total` | counter | server, kind, outcome | Finished streams: complete, client_disconnect, upstream_error. |
| `jmp_range_requests_total` | counter | server | Requests forwarded with a Range header. |
| `jmp_hls_playlist_rewrites_total` | counter | server | HLS playlists rewritten to point at the proxy. |
| `jmp_rewrites_total` | counter | rewriter | Response rewriter stages applied (json_ids, hls, location, ...). |
| `jmp_hls_segment_requests_total` | counter | server | HLS segment requests proxied. |
| `jmp_config_reloads_total` | counter | outcome | Config reload attempts: success, error, unchanged. |
| `jmp_config_last_reload_timestamp_seconds` | gauge | - | Unix time of the last successful config (re)load. |
| `jmp_config_generation` | gauge | - | Incremented on each successfully applied config. |
| `jmp_config_upstreams` | gauge | - | Configured enabled upstreams. |
| `jmp_config_users` | gauge | - | Configured proxy users. |
| `jmp_config_upstream_changes_total` | counter | change | [[server]] changes applied on reload: added, removed, rebuilt (server URL changed), changed (TLS/credentials/timeout, in place). |
| `jmp_servers_active` | gauge | - | Backends currently serving requests (enabled [[server]] entries). |
| `jmp_servers_draining` | gauge | - | Removed or rebuilt backends still finishing in-flight requests/streams. |
| `jmp_servers_retired_total` | counter | outcome | Backends retired after removal/rebuild: drained (all requests finished) or timeout (proxy.drain_timeout_secs hit). |
| `jmp_server_drain_duration_seconds` | histogram | - | Time from removal/rebuild until a backend was retired. |
| `jmp_removed_server_requests_total` | counter | - | Requests for ids of a [[server]] that was removed (answered 410 Gone). |
| `jmp_tls_reloads_total` | counter | target, outcome | TLS material reloads (target: listener, upstream). |
| `jmp_tls_cert_expiry_timestamp_seconds` | gauge | cert | notAfter of loaded certificates as unix time (cert: listener or upstream:<name>). |
| `jmp_secrets_rewritten_total` | counter | kind | Secrets rewritten in config file: user_password, upstream_password, upstream_api_key. |
| `jmp_secret_rewrite_failures_total` | counter | - | Config file secret rewrite failures (permission/IO errors). |
| `jmp_secret_decrypt_failures_total` | counter | kind | Secret decryption failures during config load (wrong key or corrupted data); kind: upstream_password, upstream_api_key. |
| `jmp_build_info` | gauge | version, git_sha | Always 1; build metadata in labels. |
| `jmp_uptime_seconds` | gauge | - | Seconds since process start. |
| `jmp_tokio_workers` | gauge | - | Tokio runtime worker threads. |
| `jmp_tokio_alive_tasks` | gauge | - | Tokio tasks currently alive. |
| `jmp_tokio_global_queue_depth` | gauge | - | Tasks waiting in the Tokio global queue. |
